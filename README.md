# Auto7Car Service - site institucional

Site one-page da **Auto7Car Service**: revisão veicular completa na Av. Orosimbo Maia, 920, Vila Itapura, Campinas - SP.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato com mapa, FAQ)
styles.css   # estilos (preto e vermelho do logo, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Serviços:** o perfil diz só "Revisão Veicular Completa". Os cards de troca de óleo e filtros, freios e suspensão, e a lista do que entra na revisão, são uma proposta. Confira com o catálogo do WhatsApp.
- **Dias de atendimento:** só o horário (8h às 18h) é conhecido. Confirme se abre aos sábados.
- **Logo:** `assets/logo-auto7.png` foi recortado do print do perfil (cerca de 144px). Troque pelo arquivo original.
- **Fotos:** de banco de imagens. Fotos reais da oficina e da fachada ajudam o cliente a reconhecer o lugar.
- **Depoimentos:** não há seção de depoimentos para não publicar avaliações inventadas.
